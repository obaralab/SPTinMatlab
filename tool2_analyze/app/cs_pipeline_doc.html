The ContactSites pipeline — what happens when you press Run

Single-particle tracking → localization-density maps → you pick contact sites → tracks are mapped to each site → you refine boundaries → the result is built. VAPB ER–mitochondria contact sites (Obara et al., Nature 626:169, 2024).

To run the whole thing, leave start stage on density and press Run / Resume. The pipeline runs on its own and pauses only at the two steps that need your mouse — picking and refining — which open inside the 6 · Contact Sites tab. When it finishes, 7 · CS Results opens automatically.

density→ locdens→ quickplot→ PICK · csid→ mapper→ part2→ snaprename→ REFINE · refiner→ ensemble→ builder→ accum

The stages, one by one

StageWhat it doesProduces
Automatic · build the density maps
density Bins every localization of each cell into a whole-cell density map at 30 nm pixels, lightly Gaussian-smoothed (σ = 2 px) and turbo-coloured. This is the base image every later stage measures on. (Per-cell contrast — not the cross-cell density PMF used for the metrics CSV.) Densities/<file>_rho.tif
locdens Same 30 nm binning per cell, saved as the density background the picker and refiner draw on. Density_<file>.tif / .mat
quickplot optional Overlays each cell’s trajectories on its max-intensity structure image — visual QC only. Skipped when there is no MaxInt/ folder (this pipeline’s Import-QC tab does this better). figures only (nothing saved)
You pick the sites
csid YOU The density picker opens in the Contact Sites tab. It auto-detects density peaks that a statistical null model rules out as chance (Monte-Carlo CSR, Poisson, ER-weighted, or local-background), and you add/remove points by hand. Each point is auto-classified mito vs non-mito by sampling the mitochondria image underneath it. Needs your input. csIDs/<base>_CSsites.txt
Automatic · map tracks to sites
mapper Crops a fixed window around each picked point and records which tracks and localizations fall inside it — this defines every site’s candidate track pool. TrackData/<base>_CSdata.mat
+ per-site density snapshots
part2 Tabulates each cell’s mito vs non-mito site counts and reassembles the per-cell track structures into one array, tagging every cell with its mito-CS index. CSindexing.mat
Tracks_final.mat
snaprename Files the mapper’s per-site snapshots into the canonical layout (moves CSdata/ to CSsnaps/, makes a fresh CSdata/ for the refiner). Idempotent. CSsnaps/ + fresh CSdata/
You refine the boundaries
refiner YOU The freehand refiner opens in the Contact Sites tab. For each site you click the refined centre and freehand-trace the boundary on a site-local 30 nm density map (a ±2.4 µm window). It writes back the refined geometry, an ellipse fit, and which localizations fall inside. A site you pass without drawing is dropped; use “Use full box” to keep it un-refined. Needs your input. CSdata/<base>_CSdata.mat (refined)
Automatic · finish & export
ensemble JBM only Aggregates per-localization effective diffusion (Deff) inside vs outside contact sites into Excel/MAT tables. Runs only on the JBM/Deff branch (needs tessellation Maps); skipped on this pipeline. CSoutput.xlsx / .mat
builder Assembles CS_final.mat — the one data structure holding every contact site (member tracks, refined boundary + centre, centred track matrix, mito flag, ellipse fit…). This is what Tabs 7 & 8 read. It is the main result. CS_final.mat
accum slow optional Writes the Excel summary table plus ~9 QC images per site (turbo/jet density, tracks, vectors, boundary, ellipse…). These are export/figure artifacts — the app never reads them. Untick “Excel + reference images” to skip it. CS_details.xlsx + CS_turbo/ CS_jet/

builder vs accum — the important distinction

builder = the result (data)

Produces CS_final.mat: the numbers and geometry for every site. Required. Tabs 7 & 8 read it directly. Cheap — just assembles a struct.

accum = the export (pictures)

Produces the Excel table + hundreds of per-site PNG/SVG images for your figures and records. Optional, and nothing in the app consumes it. Slow — 9 renders × every site.

Refining vs. exporting

Adjusting a site’s boundary re-runs only builder, so Tabs 7 & 8 update right away; a re-refine intentionally skips the accum image/Excel export. When you have finished refining, run a full pipeline with “Excel + reference images” ticked once to generate the QC images and Excel for your final figures.

What you get out

  • CS_final.mat — every contact site (from builder); read by Tabs 7 & 8.
  • cs_density_metrics.csv — per-site density PMF metrics (prob-mass, peak, enrichment), written by the app itself, not the accum.
  • csIDs/*_CSsites.txt — your picks; CSdata/*_CSdata.mat — refined per-cell site data.
  • If you run accum: CS_details.xlsx + the per-site image folders above.

Tips

  • Full run: leave start stage on density and press Run.
  • Resume: set start stage to any stage (e.g. refiner) to continue without redoing the earlier work. Stop after ends the run early.
  • While refining a lot: keep “Excel + reference images” unticked so Results opens immediately after builder; tick it for one final export run.
  • Mito vs non-mito is set during picking (auto from the mito image) and can be toggled in the refiner — it decides which sites count as ER–mitochondria contacts.
  • The line above updates to describe whichever start stage you select.
