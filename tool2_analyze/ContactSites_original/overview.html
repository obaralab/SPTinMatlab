01

What the project measures

One tether protein, tracked one molecule at a time, to read the structure of an organelle interface that is too fragile to fix and image conventionally.

VAPB (VAMP-associated protein B) is a model ER-membrane tether that helps hold the endoplasmic reticulum against mitochondria at ER–mitochondria contact sites (ERMCSs) — hubs for lipid, calcium, and metabolite exchange. The team labels VAPB with a HaloTag/PA-JF646 dye and images single molecules by sptPALM on a custom three-camera TIRF microscope, simultaneously recording the ER and mitochondria structure in two other channels.

Tracking individual molecules — rather than bulk fluorescence — lets the pipeline ask three questions the paper answers: where VAPB concentrates (contact-site boundaries from a localization-density map), how fast it moves at each point (an effective diffusion coefficient, Deff), and how long individual molecules stay (dwell-time / entry–exit kinetics). The headline result is that contact sites contain diffusion subdomains of reduced mobility that track ER membrane curvature, and that VAPB molecules enter and leave in seconds even though the site persists — a metastability that an ALS-associated VAPB mutation disrupts.

06

Reading it as an engineer

A research codebase with the reproducibility profile that implies — worth knowing before you re-run it.

Lives outside this repo

  • The JBM / Masson Deff engine — only Maps/*.mat outputs are read (via external AssimilateTessIndex3)
  • The Calderon non-parametric-Bayesian HDP-SLDS Python code + model fitting
  • TrackMate, MaskParticles.ijm, and the ChrisPrograms TIFF-I/O class

Human-in-the-loop by design

  • Interactive thresholding & multipoint CS-center picking (Fiji)
  • Wacom freehand boundary tracing of every site
  • Manual “North” + exit count for averaging; hand-marked binding events
  • Blinding is applied only to the external Bayesian step

Structure & versioning

  • Mostly bare scripts run from a specific working directory, not parameterized functions
  • Near-duplicate variants dominate: *NoDeff, *NoJBM, *_wacom, v2/v3, plus a whole Final/Revision/ branch
  • Units to watch: X/Y in µm but refboundary in nm; frame period hardcoded 0.011 s

Confirmed defects (see BUGS_AND_FIXES.md)

  • Revision/CS_builder.m — two collapsed loops build only one CS; use the top-level Final/CS_builder.m
  • EntryExitManualClassifier.m highlights the wrong track — use v2
  • CSaveragerNoDeff.m — stray token = syntax error
  • AssignCSindexByCellv2.m — references an undefined variable
